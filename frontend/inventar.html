Code: Bereich, Schrank, Ebene, Position, z.B. EL-S2-E3-P4 = Elektronik, Schrank 2, Ebene 3, Platz 4. Ebenen zählen von oben nach unten, Positionen von links nach rechts. Die 0 heisst «nicht unterteilt oder noch nicht festgelegt» (S0 = im Bereich ohne Möbel, E0 = Ebene offen, P0 = kein fester Platz). Auf Etiketten entfallen abschliessende Nullen.
Nur veraltete Mit Ebenen
Je Möbel ein Etikett (QR führt zum Inhalt), optional je Ebene ein kleines. Nach dem Drucken «Als gedruckt markieren».
Eine Zeile pro Werkzeug: Name ; Synonyme ; Code ; Menge (Trennzeichen ; oder Tab — Zeilen aus Excel lassen sich direkt einfügen). Synonyme, Code und Menge sind optional. Der Code darf gekürzt sein: EL-S2 = Elektronik, Schrank 2, Ebene offen. Fehlt der Code, wird das Werkzeug «ohne Platz» angelegt und kann später zugeordnet werden.
